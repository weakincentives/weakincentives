# M10 — Typed Boundaries: `session_id` + De-Dynamic Access

**Depends on:** none. **Unlocks:** lower type-escape baseline for M16.
**Dimensions:** 4 (type safety), 13, 3. **Priority:** high (reach). **Size:** S–M.
**Risk:** low.

## Objective

Replace runtime attribute-probing (`getattr`/`hasattr`) with real types, starting
with the single most-repeated escape: `session_id`.

## Why

~20 sites do `getattr(session, "session_id", None)` because `SessionProtocol`
(`runtime/session/protocols.py`) never declares `session_id`, though the concrete
`Session` has it. Two independent adapter reviewers flagged this; several other
`getattr`/`hasattr` sites probe statically-known attributes. Each is a typo/None
foot-gun on hot dispatch paths.

## Scope

- **`session_id` on the protocol** — add `session_id: UUID | None` (property) to
  `SessionProtocol`; replace the ~20 `getattr` sites, e.g. `_shared/_bridge.py:506`,
  `acp/adapter.py:309,441`, `acp/_events.py:71`,
  `claude_agent_sdk/adapter.py:101,266,584`, `_hook_tools.py:300`,
  `codex_app_server/adapter.py:164`, `_response.py:93`, `_events.py:95`,
  `_protocol.py:83`.
- **`_validators` task-example checks** — `prompt/_validators.py:353-486`: type via
  `*Like` Protocols (or a `TYPE_CHECKING` import of the concrete
  `TaskExample`/`TaskStep`/`ToolExample`); drop the 7 `getattr` and the now-
  unreachable `# pragma: no cover` branches.
- **`ToolInvoked.result`** — `runtime/.../session_telemetry.py:71`: type the union,
  replace `hasattr(result, "value")` with `isinstance` narrowing.
- **`digests.py`** — `contrib/tools/digests.py:77,93,107`:
  `getattr(digest, "section_key", None)` → `digest.section_key` (a required field).
- **mailbox serde** — `contrib/mailbox/_redis.py:338`: use `is_dataclass` uniformly
  (not `hasattr("__dataclass_fields__")`); narrow `body_type`.

## Exit criteria

- `SessionProtocol.session_id` exists; the ~20 `getattr` sites are gone; per-package
  `getattr`/`hasattr` counts drop.
- `make check` green.
