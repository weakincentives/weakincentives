# M16 — Type-Escape Reduction (cast/ignore burn-down)

**Depends on:** none (interleaves with everything). **Dimensions:** 4.
**Priority:** high (reach). **Size:** L (phase per package). **Risk:** med.

## Objective

Drive down the type-escape hatches by giving the underlying types the
expressiveness they were standing in for — classifiers, protocol conformance,
generics — so annotations become the source of truth again.

## Why

Post-rebase: **316** `cast(`, **82** `# pyright: ignore`, **14** `# ty: ignore`,
concentrated in `serde`/`runtime`/`prompt`/`adapters`. (#1162 already did
construction-validation + frozen-dataclass hardening, which barely moved these —
the remaining escapes are the classifier/protocol shaped ones below.) Clusters
mark missing abstractions, not 300 unrelated holes.

## Scope (delete the escape *with* the fix; never relocate it)

- **serde** — one `_typeclass.py` `TypeKind` classifier unifying the duplicated
  type taxonomy in `schema.py` and `_coercers.py`; replace the `_NOT_HANDLED`
  sentinel with a typed `CoerceResult`.
- **runtime** — make the event dataclasses satisfy `SupportsDataclass` (delete the
  duplicated `cast` blocks in `_session_helpers.py`/`session_telemetry.py`); a
  `frozen_map` helper for the ~18 `MappingProxyType` casts in `snapshots.py`.
- **prompt** — one `GenericArgCapture` for `Tool`/`PromptTemplate`/`Section` (three
  parallel specialization mechanisms today); make the `_prompt_resources` contract
  members public (drops ~10 `reportPrivateUsage`).
- **adapters** — parse JSON-RPC frames once at ingress into the existing TypedDicts
  (`codex_app_server/_protocol.py`); tagged-union notifications.
- **ratchet** — add a `toolchain` checker with a per-package `cast`/`ignore`
  baseline (mirroring `code_length_baseline.txt`) so the count only falls.

## Exit criteria

- Per-package `cast`/`ignore` counts hit the ratchet target; ty + pyright strict
  green at each phase. `make check` green.
