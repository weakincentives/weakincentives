# M16 — Observability Consolidation (Debug Bundle / Query)

**Release:** R3. **Depends on:** none. **Unlocks:** [M13](M13.md), [M15](M15.md).
**Dimensions:** 1, 5, 8. **Priority:** med–high (substrate). **Size:** L.
**Risk:** med.

## Objective

Consolidate the debug-bundle write/read and SQL-projection stack — the substrate
that record/replay (M13) and eval (M15) build on — and derive its schema from the
dataclasses instead of re-typing it three times.

## Why (first principles)

Record/replay and eval need a clean, single-source bundle/query layer. Today the
review found ~700 LOC of duplication here: ~10 hand-written `CREATE TABLE` +
flatten-insert clones (`cli/_query_builders.py` + `_query_environment.py`); the
environment schema typed three times (`debug/environment.py:105-218`, the SQLite
DDL, `cli/_bundle_store.py:536-629`); the bundle zip re-opened 5× with a dead
`_zip_file` field; 11 swallow-all `except` blocks in `BundleWriter` that can yield
silently-incomplete bundles; and a `BundleStore` late-import that exists only to
satisfy a monkeypatch (violates `CLAUDE.md`).

## Scope

- Replace the table builders with a table-spec descriptor + one `_build_kv_table`.
- Derive env columns + UI projection from the dataclass fields via `serde`.
- Open the bundle zip once (context manager); delete the dead `_zip_file`.
- One `_safe_write(name, fn)` that records capture failures into the manifest.
- Collapse the `_docs.py` doc iterators; inject the bundle-lister (drop the
  monkeypatch); fix SQL identifier quoting at `_query_tables.py:114-133`.

## Exit criteria

- ~700 LOC removed; SQLite output byte-identical (or `_SCHEMA_VERSION` bumped); no
  late-import-for-monkeypatch; the bundle is the clean record substrate for M13.
- `make check` green.
