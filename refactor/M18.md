# M18 — Error-Handling & Concurrency + Coverage-Mask Audit

**Depends on:** none. **Dimensions:** 6, 7, 9, 10. **Priority:** med. **Size:** M.
**Risk:** low–med.

## Objective

Close the swallowed-error, decorative-lock, and coverage-mask gaps the review
surfaced — make every `# nosec`/`# pragma: no cover` justified or gone.

## Why

- **RedisMailbox** — `_lock` is decorative (acquired only in `close()`; `_closed`
  is read unlocked in `send`/`receive`); the reaper wraps `_reap_expired` in
  `suppress(Exception)`, hiding Redis connection failures indefinitely on a class
  documented as multi-process.
- **Over-broad catch** — `codex_app_server/adapter.py:268` `except BaseException`
  (cleanup) also swallows `KeyboardInterrupt`/`SystemExit`/`CancelledError`.
- **Coverage masks** — real paths hidden behind pragmas: the bundle
  token-aggregation loop (`_agent_loop_bundle.py`, also a swallowing
  `except … pass`), the hook feedback path (`_hook_tools.py`), the `_docs.py`
  `# pragma: no branch`, and `_validators` type-mismatch branches.
- **Unescaped SQL identifiers** — `cli/_query_tables.py:114-133` wraps
  bundle-controlled column names in quotes without escaping, behind `# nosec B608`.

## Scope

- Make `_closed` a plain flag and delete the decorative `_lock` (atomicity is in
  Lua + the `threading.Event`); narrow + log the reaper suppression.
- Replace `except BaseException` with `try/finally` / `ExitStack`.
- Add tests and drop the pragmas hiding real paths; narrow swallowing `except`s to
  expected types.
- Route SQL column identifiers through the sanitizer (or double the quote); tighten
  the `# nosec` to the now-safe construction.

## Exit criteria

- Every surviving `# nosec`/`# pragma: no cover` is justified in-comment; no
  swallowed background failures.
- `make check` green.
