# M13 — Shared Adapter Primitives

**Depends on:** [M12](M12.md) (shares the `_shared` consolidation). **Dimensions:**
5, 6, 13. **Priority:** high. **Size:** M–L. **Risk:** med.

## Objective

Hoist the remaining per-adapter machinery that should be shared — ephemeral home,
MCP server construction, bridge telemetry labels, error normalization, and the
empty-response hook — into `adapters/_shared`.

## Why

The largest duplication in the biggest package (`adapters`, ~14.5k LOC):

- **Ephemeral home** — `claude_agent_sdk/_ephemeral_home.py` and
  `codex_app_server/_ephemeral_home.py` share a byte-identical `_copy_skill` +
  mount/lifecycle (~150 LOC); since the review, `opencode_acp` grew a **third**
  copy. The only real difference is the skills subdir (`.claude/skills` vs
  `.agents/skills`).
- **MCP builder** — `_shared/_bridge.py` and `acp/_mcp_http.py` both register
  `BridgedTool`s via `asyncio.to_thread`; two registration paths to keep in sync.
- **Mislabeled telemetry** — `_shared/_bridge.py` logs `"claude_agent_sdk.bridge.*"`
  (lines 237–655) and defaults `adapter_name="claude_agent_sdk"` (193, 525) even
  when acp/codex call it, so their tool telemetry is mis-attributed.
- **Error normalization** — Codex has none (`adapter.py` flattens all errors to
  `phase="request"`; duplicated `except CodexClientError` blocks); Claude's is
  partly stringly-typed.
- **Empty-response hook** — opencode/gemini differ only by a label and hardcode
  `prompt_name=""`.

## Scope

- Extract `_shared/_ephemeral_home.py` (base `EphemeralHome(skills_subdir=…)` +
  `_copy_skill`); the three adapters become thin subclasses.
- Move the MCP tool-server builder into `_shared` (single registration path).
- Neutralize bridge log events to `"bridge.*"`; make `adapter_name` a required arg.
- Add a `_shared` error-normalization facade; extract the `[-8192:]` stderr-tail
  constant.
- Shared empty-response helper that threads `prompt_name`; one `_noop`.

## Exit criteria

- ~300 LOC removed; the three ephemeral homes become one base + thin subclasses;
  acp/codex tool telemetry is correctly labeled.
- `make check` green.
