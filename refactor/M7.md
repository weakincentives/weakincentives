# M7 — One Evidence Pipeline

**Core:** Evidence. **Release:** R3. **Depends on:** none (consolidation first;
replay benefits from M5's `FakeHarness`). **Unlocks:** [M9](M9.md). **Size:** L.
**Risk:** med.

## Objective

One schema'd record of what happened — events → transcript → bundle — read
through one path, plus **`ReplayTrace`**: deterministic replay of a run against
recorded responses.

## Why (first principles)

*Evidence is a core, currently three copies of itself.* The bundle is read by
three independent surfaces that each re-derive its shape (`DebugBundle`,
`QueryDatabase`/`_query_builders`, `BundleStore`); the environment schema is
typed **three times** (`debug/environment.py:105-218` dataclasses, the SQLite DDL
in `cli/_query_environment.py`, and a hand-written `SELECT` in
`cli/_bundle_store.py:536-629`); ~10 `CREATE TABLE` + flatten-insert clones total
~600 LOC; the zip is re-opened five times per read with a dead `_zip_file` cache
field (`debug/_bundle_reader.py:47,54`); and `BundleWriter` swallows failures in
11 copy-pasted `except Exception` blocks, so a "successful" bundle can silently
lack Required artifacts. Replay — the payoff — needs this substrate to be single
and trustworthy first.

## Stages (each lands green)

1. **Consolidate the bundle** — table-spec descriptor + one generic
   `_build_kv_table` (deletes the builder clones); derive env columns and the UI
   projection from the dataclasses via `serde`; open the zip once (context
   manager; delete the dead field); one `_safe_write(name, fn)` recording capture
   failures into the manifest; inject the bundle-lister (removes the
   late-import-for-monkeypatch in `_bundle_store.py:633-635`); fix SQL identifier
   quoting at `cli/_query_tables.py:114-133`.
1. **`ReplayTrace`** — a serde artifact distilled from the transcript/bundle: the
   ordered prompt renders, tool calls + results, model outputs, usage, and the
   negotiated capabilities (M6). Record mode emits it alongside the bundle.
1. **Replay** — a trace-driven fake adapter (built on M5's `FakeHarness`) +
   `FakeClock` re-runs the definition deterministically. Assert identical
   behavior against the *same* recorded responses; **diff** behavior when the
   definition, model, or harness changes — the diff is the expected, useful
   output, not a conformance failure. `wink replay <trace> [--diff <other>]`.

## Exit criteria

- ~700 LOC removed from the bundle/query stack; SQLite output byte-identical or
  `_SCHEMA_VERSION` bumped; capture failures are visible in the manifest.
- A recorded run replays to identical session state; a definition change
  surfaces as a structured diff.
- `make check` green.
