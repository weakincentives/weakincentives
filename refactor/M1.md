# M1 — Filesystem: Narrow Backend + One Facade

**Depends on:** nothing. **Unlocks:** [M3](M3.md), [M6](M6.md).

## Objective

Replace the fat `Filesystem` protocol — reimplemented in full by every backend —
with a **narrow `FilesystemBackend`** (≈10 primitives) and a **single concrete
`Filesystem` facade** that composes all ergonomics (text, bytes, pagination,
streaming) once, over any backend.

## Why (first principles)

"Narrow capabilities, ergonomic facades." A storage backend should only have to
say how to read a byte range, write bytes, list, search, and snapshot. Everything
else — line pagination, UTF-8 decoding, chunked readers/writers, the 32 MB
convenience caps — is pure composition that must not be duplicated per backend.
This is also what makes a *remote* backend cheap (M6): it implements the same ten
methods, nothing more.

## Scope

**New**

- `filesystem/_backend.py` — `FilesystemBackend` protocol (`root`, `read_only`,
  `stat`, `list`, `glob`, `grep`, `read_range`, `write`, `delete`, `mkdir`,
  `snapshot`, `restore`). `SnapshotRef` replaces `FilesystemSnapshot` (rename;
  carries the opaque backend ref).
- `filesystem/_facade.py` — `Filesystem`, one concrete class wrapping a
  `FilesystemBackend`. Implements `read`/`read_bytes`/`write`/`write_bytes`,
  `open_read`/`open_write`/`open_text`, `exists` (via `stat`), and delegates
  `list`/`glob`/`grep`/`delete`/`mkdir`/`snapshot`/`restore`.
- `filesystem/_streams.py` — one `ByteReader`/`ByteWriter`/`TextReader` impl over
  a backend (range reads; buffered append writes).

**Rewrite**

- `filesystem/_host.py` → `HostBackend` (primitives only).
- `contrib/tools/filesystem_memory.py` → `filesystem/_memory.py` `MemoryBackend`.

**Delete**

- `filesystem/_protocol.py` (fat protocol), `_stream_host.py`, `_stream_memory.py`,
  `_stream_text.py`, and the per-backend halves of `_streams.py`/`_stream_protocols.py`.
- The `SnapshotableFilesystem` protocol — snapshot is now a backend capability.

## New shape

```python
@dataclass(slots=True)
class Filesystem:                       # the only implementation tools see
    backend: FilesystemBackend

    def read(self, path, *, offset=0, limit=None, encoding="utf-8") -> ReadResult: ...
    def open_text(self, path, *, encoding="utf-8") -> TextReader: ...
    # …all built on backend.read_range / backend.write…
    def glob(self, pattern, *, path=".") -> Sequence[GlobMatch]:
        return self.backend.glob(pattern, path=path)
```

`grep`/`glob` stay on the backend so remote backends run them **server-side**.

## Risks & mitigations

- *Behavior drift in pagination/encoding.* Mitigate by keeping `_types.py`
  result dataclasses and porting the existing edge-case tests verbatim against
  the facade.
- *Coverage.* The facade concentrates logic, so coverage is easier, not harder.

## Exit criteria

- `tests/filesystem/` (the `FilesystemValidationSuite`) passes against `Filesystem`
  over both `HostBackend` and `MemoryBackend`.
- Net deletion of ≳1,000 lines from `filesystem/` + `contrib`.
- `make check` green.
