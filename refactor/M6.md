# M6 — Remote Facets Over a Transport

**Depends on:** [M1](M1.md), [M3](M3.md). **Unlocks:** [M7](M7.md).

## Objective

Implement a `Sandbox` whose facets live elsewhere: a narrow `SandboxTransport`
and the remote backends (`RemoteBackend`, `RemoteShell`, `RemoteSandbox`) built on
it. No provider wiring yet — this milestone is the wire and its contract tests.

## Why (first principles)

"Local and remote differ only in transport." Because M1 made the filesystem a
narrow backend, a remote filesystem is just that same ten-method backend
implemented over RPC — there is no streaming/text/pagination to re-port. The
transport is correspondingly small.

## Scope

**New — `sandbox/_transport.py`**

`SandboxTransport` protocol — one method per backend/shell primitive:

| Group | Methods |
|-------|---------|
| Metadata | `stat`, `list` |
| Bytes | `read_range`, `write` |
| Search | `glob`, `grep` — **executed server-side** |
| Mutate | `delete`, `mkdir` |
| Snapshot | `snapshot`, `restore` |
| Exec | `exec(argv, cwd, env, stdin, timeout)` |

**New — `filesystem/_remote.py`, `sandbox/_remote.py`**

- `RemoteBackend(transport)` — implements `FilesystemBackend` by forwarding each
  primitive; maps transport faults to the protocol's exception contract
  (`FileNotFoundError`, `PermissionError`, …; connectivity → `RuntimeError`).
- `RemoteShell(transport)` — implements `Shell` via `transport.exec`.
- `RemoteSandbox(transport)` — `filesystem = Filesystem(RemoteBackend(...))`,
  `shell = RemoteShell(...)`; `close()` tears down the transport.

**Test infra**

- An in-process **loopback transport** that drives a `HostBackend`/`LocalShell`
  over the `SandboxTransport` interface (no sockets).

## Risks & mitigations

- *Chattiness.* Server-side `glob`/`grep` and range reads keep round-trips bounded;
  document a max round-trip budget for `Filesystem` convenience calls.
- *Blocking the event loop.* Remote calls are sync; adapters offload via
  `asyncio.to_thread`, as `BridgedTool` already does.

## Exit criteria

- The existing `FilesystemValidationSuite` passes against `Filesystem` over
  `RemoteBackend` + loopback transport (full contract, no network, `FakeClock`).
- `RemoteShell` passes the M2 `Shell` contract over loopback.
- Transport-fault → protocol-exception mapping is unit-tested.
- `make check` green.
