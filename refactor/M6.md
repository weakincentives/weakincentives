# M6 — The Harness Contract

**Core:** Contract. **Release:** R2. **Depends on:** [M5](M5.md) (FakeHarness for
contract tests), R1 (sandbox scenarios). **Size:** L. **Risk:** med.

## Objective

Make the seam **small, declared, and proven**: consolidate the duplicated turn
machinery into `_shared` (shrink it), introduce `AdapterCapabilities` negotiation
(declare it), and realize the ACK conformance suite from `specs/ACK.md` (prove
it). A new harness becomes a leaf package + a capability declaration + a green
ACK run.

## Why (first principles)

*Volatility at the edges; capabilities, not conditionals; portability is
contract-level.* The seam is where 2–3 years of harness churn will hit, so it
must be narrow — yet `adapters/` is the largest package (14.5k LOC) with the turn
loop implemented **three times** (`acp/_prompt_loop.py:157-246`,
`codex_app_server/_protocol.py:180-247`,
`claude_agent_sdk/_sdk_execution.py:140-220`), guardrails twice
(`acp/_guardrails.py` ≡ `codex…/_guardrails.py`, ~110 LOC), the ephemeral home
**three times**, and the shared bridge mislabeling everyone's telemetry as
`claude_agent_sdk.bridge.*` (`_shared/_bridge.py:193,237-655`). Harness
*differences*, meanwhile, are real and growing (Gemini: no usage reporting,
HTTP/SSE-MCP only; Codex: `sandbox_mode`; SDK: OS isolation) and today leak as
silent misbehavior. `specs/ACK.md` already defines the answer — a contract-first,
capability-gated suite that explicitly does **not** test output equality ("that's
evals") — it just isn't implemented.

## Stages (each lands green)

1. **Shrink** — one `_shared/_turn_loop.py::run_continuation_loop(send_turn, …)`
   (adapters pass a one-turn closure); `check_task_completion`/`append_feedback`
   into `_shared/_guardrails.py` (parameterize the content key); one
   `_shared` ephemeral-home base (`skills_subdir=…`) replacing the three copies;
   one MCP tool-server builder; de-brand bridge logs (`bridge.*`,
   `adapter_name` required); a shared error-normalization facade (Codex currently
   flattens everything to `phase="request"`, `adapter.py:351-366`).
   Note: the per-adapter `evaluate` preamble (budget→tracker, effective
   deadline, expiry fail-fast) was already hoisted into
   `AgentRuntime.evaluate` as part of [M3](M3.md)'s landed amendments —
   `_evaluate` is a thin `run_async` wrapper, so the shrink targets only
   the turn machinery listed above.
1. **Declare** — `AdapterCapabilities`, one descriptor per adapter (reconciling
   the table in `specs/ACK.md` with runtime needs: structured output, usage
   reporting, sandbox modes, skills, MCP transport, cancellation, native tools).
   Definitions state `requires=(…)`/`prefers=(…)`; negotiation at bind/evaluate:
   satisfy → run; unmet preference → degrade + log; unmet requirement → fail
   closed with a typed error naming the gap, **before any model call**. The
   negotiated result lands in telemetry.
1. **Prove** — implement `integration-tests/ack/` per the spec: `AdapterFixture`
   protocol, scenario tiers 1–4 + adapter-specific, transcript-as-oracle helpers;
   scenarios gated on the *same* `AdapterCapabilities` (unsupported → `SKIPPED`,
   never `FAILED`); add R1 sandbox-parity scenarios (filesystem, shell, egress
   reconfiguration honored at the contract level). **Delete** the eleven
   duplicated per-adapter integration files (the spec's "What Gets Deleted"
   table); run ACK as a CI matrix job.

## Exit criteria

- One turn loop, one guardrail module, one ephemeral home, one MCP builder;
  `grep 'adapter_name =='` matches nothing outside telemetry.
- Unmet hard requirement fails closed pre-flight; ACK green for
  `claude_agent_sdk`, `codex_app_server`, and the ACP family; old integration
  files gone.
- `make check` (unit) green; ACK green in the CI matrix.
