# M12 — Realize the ACK Contract Suite

**Release:** R2. **Depends on:** [M10](M10.md), [M11](M11.md), and the `_shared`
adapter consolidation (BACKLOG hardening). **Dimensions:** 10, 13, 5.
**Priority:** high (mission). **Size:** L.

## Objective

Build the **one** capability-gated suite, from `specs/ACK.md`, that every adapter
must pass — verifying each honors the WINK **contract** (events, transcripts,
tool bridging, structured-output *request*, transactional rollback), **not** that
outputs are identical.

## Why (first principles)

*Portability is contract-level.* `specs/ACK.md` already specifies exactly this — it
is contract-first and explicitly **"does NOT validate content correctness… that's
evals,"** with capability gating so immature adapters skip rather than fail. But it
is a spec, not yet the unified implementation: per-adapter integration tests are
still duplicated and drifting (the spec enumerates the copies). Realizing ACK turns
"define once, run on any harness" from a claim into a gate.

## Scope

- Implement `integration-tests/ack/` per the spec: the `AdapterFixture` protocol,
  scenario tiers 1–4 + adapter-specific scenarios, and the transcript/event
  assertion helpers (the "transcript as oracle" strategy).
- Gate scenarios on M11's `AdapterCapabilities` (one descriptor for runtime and
  tests); unsupported → `SKIPPED`, never `FAILED`.
- Add **sandbox-parity** scenarios from R1: `filesystem`, `shell`, and egress
  reconfiguration honored identically at the *contract* level.
- **Delete** the duplicated per-adapter integration files (the spec's "What Gets
  Deleted" table); run ACK as a CI matrix job (excluded from unit `make check`).

## Exit criteria

- ACK is green for `claude_agent_sdk`, `codex_app_server`, and the ACP family in
  CI; the old per-adapter integration files are gone; gaps are capability-gated
  skips tied to M11, not silent.
- `make check` (unit) green; ACK green in the CI matrix.
