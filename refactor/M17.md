# M17 — Prompt Selection/Render DRY

**Depends on:** none. **Dimensions:** 5, 6. **Priority:** med. **Size:** S–M.
**Risk:** low.

## Objective

Collapse the two copy-pasted prompt mechanisms the review found.

## Why

- `_enabled_predicate.py` and `_visibility.py` are the same 2×2 normalizer twice
  (~120 LOC; `*_requires_positional_argument` is byte-identical except its return
  type) — they differ only in the result type (`bool` vs `SectionVisibility`).
- `Section.render` and `MarkdownSection.render_override` duplicate the
  heading+body+tools assembly; `rendering.py:211` reads `accepts_overrides` via a
  defensive `getattr` even though it is always set in `Section.__init__`.

## Scope

- One generic `normalize_selector[R](selector, params_type, coerce) -> Callable[[params, session], R]`; `_visibility` passes `_coerce_section_visibility`,
  `_enabled` passes `bool`. Delete the duplicate `*_requires_positional_argument`.
- Extract `Section._assemble(heading, body, tools) -> str`; call it from both
  render paths; replace the `getattr` with a plain attribute read.

## Exit criteria

- ~120 LOC of duplication removed; one selector normalizer + one render assembler.
- `make check` green.
