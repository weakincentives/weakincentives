# M9 — Definition Modularity & Composition

**Release:** R2. **Depends on:** R1 (definitions carry a `SandboxSpec`).
**Unlocks:** [M10](M10.md). **Dimensions:** 1, 3, 5, 13. **Priority:** high
(mission). **Size:** M.

## Objective

Make an agent definition something you **compose from reusable, harness-independent
units** — and keep that independence an enforced invariant — so definitions are
structured code, not bespoke one-offs.

## Why (first principles)

*The definition is code.* `CLAUDE.md` already calls it "a first-class artifact you
can version, review, test, and port," and the 4-layer checker already forbids
`prompt/` from importing adapters — harness-independence holds today but is
incidental, not articulated. Meanwhile `code_reviewer_example.py` (~20k LOC of
example) builds its sections through ad-hoc local functions (`_create_workspace_section`,
`PromptTemplate[ReviewResponse].create(...)`, `Prompt(template).bind(...)`): a good
shape with no reusable form. We want definitions assembled from tested building
blocks, and a guarantee they never reach into a harness.

## Scope

- **Composition surface** — a documented pattern + light helpers for reusable
  **section / tool / policy packs**: a pack is a function returning a
  `Section`/`tuple[Tool, …]`/`tuple[Policy, …]` that any definition can drop in.
  Refactor the `code_reviewer_example.py` builders into the canonical example.
- **One generic-specialization mechanism** — unify the three parallel
  `__class_getitem__`/ClassVar mechanisms on `Tool`, `PromptTemplate`, and
  `Section` (review finding) into one `GenericArgCapture`, so typed composition is
  consistent and the cast cluster in `tool.py` shrinks.
- **Harness-independence invariant** — extend `toolchain/checkers` so a definition
  module (the `prompt/` surface + user definition packages) importing any
  `adapters/*` symbol fails `make check`, making the boundary explicit.

## Exit criteria

- A definition is assembled from reusable packs; `code_reviewer_example.py` uses
  them; one specialization mechanism remains.
- The checker fails on a definition→adapter import; `make check` green.
