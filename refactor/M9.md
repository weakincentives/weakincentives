# M9 — Measure & Resume

**Core:** Evidence + State. **Release:** R3. **Depends on:** [M7](M7.md).
**Size:** L. **Risk:** med.

## Objective

Close the loop on trust: agent quality is **measurable** (evals over definitions,
optionally against recorded traces) and runs are **durable** (checkpoint and
resume across a process or harness restart).

## Why (first principles)

*Contract conformance is proven by ACK (M6); quality is judged by evals — and a
run that cannot survive a restart is not trustworthy.* The pieces exist —
`evals/` (loop, datasets, judge), session snapshots, sandbox snapshots (R1), DLQ,
lease extension, heartbeats — but they don't compose into the two capabilities
users actually need: "score this definition over a dataset" and "resume this
interrupted run." Notably, the transaction unit R1 built — **(session, sandbox)**
— is already the checkpoint unit; resume is that pair plus a cursor.

## Stages (each lands green)

1. **Evals over definitions** — dataset runners + session evaluators + judge
   evaluate a definition end-to-end (live adapter) or against `ReplayTrace`s
   (M7) for fast, deterministic scoring; aggregate per-case and per-suite
   results. `wink eval <definition> <dataset>`.
1. **Checkpoint** — `Checkpoint` = session snapshot + sandbox `SnapshotRef` +
   request cursor, emitted at policy-visible boundaries (post-tool, post-turn).
   Stored via the existing bundle/slice persistence.
1. **Resume** — restore the pair, re-enter the loop at the cursor with idempotent
   re-delivery (reusing DLQ/lease/heartbeat machinery); duplicated effects are
   structurally prevented by the transactional boundary. `wink resume <checkpoint>`.

## Exit criteria

- An interrupted session resumes to completion with no duplicated effects
  (asserted via session events and sandbox state).
- An eval suite scores a definition over a dataset both live and against traces.
- `make check` green.
