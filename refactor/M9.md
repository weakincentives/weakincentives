# M9 — Portable Agent Definition Artifact

**Release:** R2. **Depends on:** R1 (embeds `SandboxSpec`). **Unlocks:**
[M10](M10.md), [M11](M11.md), [M13](M13.md). **Dimensions:** 3, 11, 13.
**Priority:** high (mission). **Size:** L.

## Objective

Make a full agent definition a **serializable, versioned, content-addressed
artifact** you can save, load, diff, and share — independent of the Python
process — so "you own the definition" is literally true.

## Why (first principles)

*The definition is data.* Today a definition is a live object graph
(`PromptTemplate` + sections + tools + policies + `SandboxSpec` + feedback). A
definition you cannot serialize, version, or diff is not a first-class artifact —
it cannot be reviewed, shared, pinned, or reproduced. We already have `serde`
(no Pydantic) and structured-output type handling; this extends them to the whole
definition. Handlers are code, so the artifact references them by **stable
identity**, resolved at load.

## Scope

- **`AgentDefinition`** (serde value): `ns`/`key`/**`version`** (semver), the
  section tree, tool **schemas + ids**, policies, `SandboxSpec`, feedback config,
  and the structured-output type reference.
- **`dump`/`load`** via `serde` to a stable on-disk format; a **content
  fingerprint** (hash of the canonical form) for reproducibility/pinning.
- **Handler registry** — resolve tool/feedback handlers by id at load; a loaded
  definition binds resources/handlers and runs unchanged on any adapter.
- **CLI** — `wink def show <path>` and `wink def diff <a> <b>`.

## New shape

```python
@FrozenDataclass()
class AgentDefinition:
    ns: str; key: str; version: str            # semver; identity
    sections: tuple[SectionSpec, ...]          # serde-able section tree
    sandbox: SandboxSpec
    output: TypeRef | None
    def fingerprint(self) -> str: ...          # content hash
# load(path) -> AgentDefinition ; bind(defn, registry, resources) -> Prompt
```

## Exit criteria

- A representative definition round-trips to disk and runs identically before/after
  `load`; the fingerprint is stable across processes.
- `wink def show`/`diff` work; `make check` green.
