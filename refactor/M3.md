# M3 — Sandbox Aggregate + Provider

**Depends on:** [M1](M1.md), [M2](M2.md). **Unlocks:** [M4](M4.md), [M6](M6.md).

## Objective

Introduce the aggregate root (`Sandbox`), its intent (`SandboxSpec`), and its
factory (`SandboxProvider` + `LocalSandboxProvider`). Move workspace
materialization — temp dir, mount copying — out of `WorkspaceSection` and into the
provider, where it belongs.

## Why (first principles)

The environment is realized **from** intent **by** a factory. Naming that factory
separates "what kind of environment" (definition) from "how it is provisioned"
(harness). It also gives local and remote a single shared seam: an adapter calls
`provider.open(spec)` and never branches on location.

## Scope

**New** — `sandbox/`:

- `_spec.py` — `SandboxSpec` (frozen): `mounts: tuple[HostMount, …]`,
  `allowed_host_roots`, `read_only`, `egress: EgressPolicy`, `env`,
  `setup: tuple[str, …]`. `HostMount` moves here from `prompt/workspace.py`.
- `_egress.py` — `EgressPolicy` (frozen, default-deny) + `EgressRule`
  (host/domain glob, ports, protocol). The initial policy seeds the proxy
  sidecar; see *Egress* below.
- `_sandbox.py` — `Sandbox` protocol + `LocalSandbox` composing a `Filesystem`
  (over `HostBackend`) and a `LocalShell`; `snapshot`/`restore` delegate to the
  backend; `egress`/`configure_egress` manage the egress proxy (local: a local
  proxy or documented no-op); `close()` removes the temp dir + snapshot store;
  idempotent.
- `_provider.py` — `SandboxProvider` protocol (`open(spec) -> Sandbox`, `close()`)
  - `LocalSandboxProvider`. `open` performs today's `_create_workspace`
    (temp dir + filtered mount copy, with the existing symlink/byte-budget guards)
    and applies `spec.egress`.

**Move**

- `_create_workspace`, `_copy_mount_to_temp`, mount validation, and
  `compute_workspace_fingerprint` from `prompt/workspace.py` into the provider.

## New shape

```python
class LocalSandboxProvider:
    def open(self, spec: SandboxSpec, *, session, run_context=None, deadline=None) -> Sandbox:
        root, previews = materialize(spec)            # was _create_workspace
        fs = Filesystem(HostBackend(root, read_only=spec.read_only))
        return LocalSandbox(id=uuid4().hex, root=root, filesystem=fs,
                            shell=LocalShell(root), _previews=previews)
```

## Egress (control-plane)

`Sandbox.configure_egress(policy: EgressPolicy)` reconfigures the sandbox's proxy
sidecar **at any time** (no restart); `Sandbox.egress` returns the effective
policy. This is harness/policy-driven control plane — **not** exposed to the model
via `ToolContext` (an agent cannot widen its own egress). Locally it drives a
local proxy or is a documented no-op; the remote wire op lands in [M6](M6.md) and
the container sidecar in [M7](M7.md).

## Risks & mitigations

- *Mount-copy parity.* Reuse the existing workspace mount tests verbatim against
  `LocalSandboxProvider`; they are the parity oracle.
- *Snapshot store cleanup.* `LocalSandbox.close()` must clean the external git
  dir (today's `HostFilesystem.cleanup`); assert no temp leakage in tests.

## Exit criteria

- `LocalSandboxProvider.open(spec)` reproduces today's mount behavior; lifecycle
  tests cover `open → snapshot/restore → close`, idempotent `close`, and
  `configure_egress` updating `sandbox.egress`.
- Not yet wired into sections/adapters (`WorkspaceSection` still works as-is).
- `make check` green.
