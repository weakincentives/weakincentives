# M2 — Sandbox Aggregate

**Core:** Environment. **Release:** R1. **Depends on:** [M1](M1.md).
**Unlocks:** [M3](M3.md), [M4](M4.md). **Size:** M. **Risk:** low.

## Objective

Name the environment. A `Sandbox` aggregate vends the two effect facets
(`Filesystem`, `Shell`) and owns egress; a `SandboxSpec` declares intent; a
`SandboxProvider` materializes it. Local first.

## Why (first principles)

*One environment, one truth — and effects need a command channel.* Today the
environment is implicit (a temp dir made by `WorkspaceSection`,
`prompt/workspace.py:267-289`) and has **no exec surface at all** — `subprocess`
appears only in internal plumbing (`filesystem/_git_ops.py`, `debug/`, `formal/`).
"All tool calls" includes shell, so a remote environment is unreachable today
even in principle. The aggregate gives lifecycle a single owner: whoever opens a
sandbox closes it; facets never self-close.

## Stages (each lands green)

1. **`Shell` facet** — `sandbox/_shell.py`: `CommandResult` (exit code,
   stdout/stderr bytes, truncated, duration) and
   `Shell.run(argv, *, cwd, env, stdin, timeout_s)`. `LocalShell` runs a
   subprocess rooted at a directory with output caps and a default timeout
   (env hygiene per `_git_ops.git_env`). Executes an `argv` vector — the name
   denotes the surface, not `/bin/sh`.
1. **`Sandbox` aggregate** — `sandbox/_sandbox.py`: protocol with `id`, `root`,
   `filesystem`, `shell`, `egress`, `configure_egress`, `snapshot`/`restore`
   (delegating to the filesystem backend), idempotent `close`. `LocalSandbox`
   composes `Filesystem(HostBackend)` + `LocalShell`.
1. **Intent + factory** — `sandbox/_spec.py`: `SandboxSpec` (frozen):
   `mounts: tuple[HostMount, …]` (moved from `prompt/workspace.py`),
   `allowed_host_roots`, `read_only`, `egress: EgressPolicy`, `env`,
   `setup: tuple[str, …]`. `EgressPolicy` is **default-deny** with
   `EgressRule(host_glob, ports, protocol)` allow entries.
   `SandboxProvider.open(spec) -> Sandbox` + `LocalSandboxProvider`, absorbing
   today's `_create_workspace` mount machinery (symlink and byte-budget guards,
   `compute_workspace_fingerprint`) verbatim — the existing workspace-mount tests
   are the parity oracle.
1. **Egress control plane** — `configure_egress(policy)` reconfigures the
   sandbox's proxy sidecar **live** (locally: a local proxy, or a documented
   no-op). Control-plane only: driven by the harness and policies, **never
   exposed to the model** via `ToolContext` — an agent cannot widen its own
   egress. The remote wire op lands in [M4](M4.md).

## Exit criteria

- `LocalSandboxProvider.open(spec)` reproduces today's mount behavior; lifecycle
  tests cover open → snapshot/restore → close, idempotent close, and
  `configure_egress` updating `sandbox.egress`.
- Not yet wired into prompts or adapters (that is [M3](M3.md)).
- `make check` green.
