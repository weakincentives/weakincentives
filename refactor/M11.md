**Depends on:** none (pair with [M9](M9.md) for the ACP spec edit).
**Dimensions:** 11 (docs/specs). **Priority:** high (zero risk). **Size:** S.
**Risk:** none (docs only).

## Objective

Erase spec/doc claims the code no longer — or never did — honor. These render
through `wink docs`, so drift misleads users directly.

## Why

The review surfaced several doc assertions with no implementation behind them.

## Scope

- **serde `__type__` polymorphism** — `serde/__init__.py:17-18,179-214` implies
  automatic discriminated deserialization, but `parse()` never reads
  `TYPE_REF_KEY` (the example shows the *caller* resolving it). Reword to "manual
  discriminator helpers."
- **`HIDDEN` visibility** — `prompt/__init__.py:43,77` documents a `HIDDEN` level;
  `SectionVisibility` has only `FULL`/`SUMMARY`. Delete the references (or document
  `enabled=` as the exclusion mechanism).
- **Debug API routes** — `DEBUG_BUNDLE.md:316-325` / `WINK_DEBUG.md` omit live
  routes (`/api/environment`, `/api/manifest`, `/api/logs/facets`,
  `/api/transcript`, `/api/transcript/facets`) present in `debug_app.py:290-305`.
  Refresh the tables.
- **ACP session reuse** — `ACP_ADAPTER.md:366-370` describes `ACPSessionState`
  session reuse that is not wired (the code is deleted in M9). Strike the section.
- **Sweep** — re-check specs touched by the sandbox arc (M1–M8) for drift as those
  land.

## Exit criteria

- Each doc claim matches code; `make check` (markdown-check + docs link/codeblock
  checkers) green.
