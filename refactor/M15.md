# M15 — Eval & Resumable Sessions

**Release:** R3. **Depends on:** [M13](M13.md). **Dimensions:** 10, 7.
**Priority:** med–high. **Size:** L.

## Objective

Make agent quality **measurable** (mature evals) and runs **durable** (checkpoint
and resume a session across a harness or process restart).

## Why (first principles)

*Trustworthy = measurable + durable.* WINK has an evals package and the resilience
primitives (session snapshots, DLQ, lease extension, heartbeats) but they don't yet
deliver "score a definition over a dataset" and "resume an interrupted run" as
first-class capabilities. Evals close the loop with replay (M13); resumability
turns the harness's crash-recovery ownership into an actual guarantee for the
definition's state.

## Scope

- **Eval**: dataset runners + session evaluators + judge integration; evaluate a
  the definition, optionally against `ReplayTrace`s (M13); aggregate scores.
- **Resume**: a `Checkpoint` = session snapshot + sandbox snapshot (R1) + cursor;
  resume after restart with idempotent re-delivery (reuse DLQ/lease). The
  transaction unit (session, sandbox) is already the checkpoint unit.
- **CLI**: `wink eval <definition> <dataset>`; `wink resume <checkpoint>`.

## Exit criteria

- An interrupted session resumes to completion with no duplicated effects; an eval
  suite scores a definition over a dataset and reports per-case results.
- `make check` green.
