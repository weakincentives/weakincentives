# M15 — CLI/Debug Bundle & Query Consolidation

**Depends on:** none. **Dimensions:** 1, 5, 8. **Priority:** high (deletion).
**Size:** L. **Risk:** med.

## Objective

Collapse the duplicated bundle read/write and SQL-projection machinery; derive the
schema from the dataclasses instead of re-typing it by hand.

## Why

- **Query builders** — `cli/_query_builders.py` + `_query_environment.py`: ~10
  hand-written `CREATE TABLE` + "iterate JSONL → json.loads → INSERT" clones
  (~600 LOC); schema is already at version 9.
- **Triple env schema** — the environment shape is typed three times:
  `debug/environment.py:105-218` (dataclasses), the SQLite DDL, and
  `cli/_bundle_store.py:536-629` (a 94-line `get_environment` with a hand-written
  `SELECT`).
- **Zip re-opened per access** — `debug/_bundle_reader.py` opens the archive 5×
  (and once per checksummed file) with a dead `_zip_file` field; every query-DB
  build re-parses the central directory a dozen+ times.
- **Swallow-all writes** — `BundleWriter` has 11 copy-pasted `except Exception`
  blocks; a "successful" bundle can silently lack Required artifacts.
- **Misc** — `_docs.py:251-281` triplicated doc iterators; the `BundleStore`
  god-object late-imports `iter_bundle_files` only to satisfy a monkeypatch
  (violates `CLAUDE.md`); unescaped SQL identifiers at `_query_tables.py:114-133`
  behind a `# nosec`.

## Scope

- Replace the table builders with a table-spec descriptor + one generic
  `_build_kv_table`.
- Derive env columns + UI projection from the dataclass fields via `serde`.
- Open the bundle zip once (context manager); delete the dead `_zip_file`.
- One `_safe_write(name, fn)` that records capture failures into the manifest.
- Collapse the doc iterators; inject the bundle-lister; fix identifier quoting.

## Exit criteria

- ~700 LOC removed; SQLite output byte-identical (or `_SCHEMA_VERSION` bumped);
  no late-import-for-monkeypatch.
- `make check` green.
